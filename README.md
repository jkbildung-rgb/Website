# Wald statt Stall

Website für waldstattstall.at: moderne Wildrezepte, Saisonkalender, Bezugsquellen.

- `index.html`: die komplette Seite
- `fonts/`: lokal eingebundene Schriften (Anton, Work Sans), keine Verbindung zu Google
- `CNAME`: verknüpft GitHub Pages mit waldstattstall.at

Veröffentlicht über GitHub Pages (Branch `main`, Ordner `/`).
